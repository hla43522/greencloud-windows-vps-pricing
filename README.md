## SuperSaving 档的折扣逻辑：季付换内存

SuperSaving 的门槛只有一条，官网原话是 "Pay at least quarterly for great discount"——至少按季度付费才能享受折扣，最低一次付三个月。换来的是同价位内存直接翻倍：$10/月给 2GB 内存，而 Normal 档要到 $16/月的 US2 才有 2GB；同样的规律在高档位也成立，$40/月的 Budget-3 给 4核 8GB，而 Normal 档 US4 花 $32/月才拿到 4GB。

## 退款条款里的四个坑，下单前必须知道

绿云的服务条款里有退款保证，但条件比多数人以为的严格。以下几条都来自官网 Terms of Service：

1. **只保新客户的首个 VPS，且限 7 天内**。条款原文是 "New clients are eligible for a refund on their first VPS plan within 7 days of account registration"，从账户注册算起，第二个订单开始就没有退款资格了。
2. **加密货币付款一律不退**。条款明确写了 Bitcoin 付款不可退款。
3. **已用掉 10% 以上分配带宽的服务不可退款**，升级过配置的服务同样退出退款范围。
4. **促销套餐不予退款**。这条在 LowEndTalk 上真的出过事：一位用户 2025 年 11 月 28 日申请取消三年期 VPS，绿云先批准终止了服务，之后以条款中“促销套餐不退款”为由拒绝退还剩余费用，客服团队在工单里反复引用 TOS 后关闭了工单，讨论帖于 2025 年 12 月 14 日被关闭。用户的质疑点在于：如果套餐真的不可退，公司应该在取消环节就拒绝，而不是先关服务再拒退款。

账单环节也有硬规定：发票在到期日前 14 天开出，逾期 2 天加收 **10% 滞纳金**，逾期 1 天就可能被暂停、3 天后终止。取消要走客户区表单（Client Area > Services > My Services > Request Cancellation），而且取消本身不等于退款。

## 它是 unmanaged 服务，别按托管预期来

普通 Windows VPS 线都是非托管（unmanaged）服务，条款写明只提供硬件功能支持，软件支持仅限订购时选的默认安装，软件配置错误导致的停机不承担责任。也就是说，系统更新、安全补丁、环境配置都是你自己的事。

两条路可以绕开这个问题：要么加钱上 Managed 托管线（$40/月起），要么自己具备基本的 Windows Server 管理能力。如果你连远程桌面都没用过，建议先从 Managed 起步，或者先在本地虚拟机里练一遍再买。

## 换 IP、换机房的规定，以及中文用户该留意的细节

条款里有一条专门针对中国客户：VPS 交付后 3 小时内如果 IP 被防火墙（GFW）封锁，可以申请免费更换一次 IP；超过这个时限，换 IP 收一次性费用，欧盟和美国 $2、亚太 $3。

换机房位置是另一回事，普通套餐 $3 一次，美欧区可以在区域内数据中心之间任意换。促销套餐的限制更严：换位置收 $10 一次，亚太区只能在同一国家内的数据中心互换（比如 SGDC1 ↔ SGDC2），部分闪购套餐还要求激活满一个月才有资格。买促销价套餐前，先想清楚机房位置是否一步到位。

同时条款也明确不保证数据中心 IP 能访问 Netflix、Etsy 这类会封禁机房 IP 的网站。对 IP 信誉敏感的业务（邮件、注册类），下单前把这条想清楚——Trustpilot 上确实有用户投诉分配到的 IP 段被列入黑名单，中文社区也有人反映过特定优化线路的连接稳定性问题，虽然都是个案，但这类用途本来就容不得侥幸。

## 几个下单前常问的问题

**Windows VPS 怎么操作？** 远程桌面（RDP）。拿到服务器信息后用 Windows 自带的远程桌面连接登录，看到的就是完整图形界面，和操作一台普通 Windows 电脑没有区别。

**1GB 内存够用吗？** 轻量任务勉强够，开浏览器多标签就会卡。内存需求超过 1GB 直接看 SuperSaving 档，$10/月就有 2GB，比 Normal 档的性价比高出一截。

**挂流量交换工具行不行？** Budget Windows VPS 页面直接标注 "Hitleap/Jingling Allowed"，这类用途在产品线上属于官方许可范围，这一点在主流服务商里比较少见。跑 SEO 工具则是另一回事：10Gbps 线明确要求搭配代理，代理需另行购买。

**跑 SEO 工具选哪条线？** 10Gbps-1（$35/月）起步，注意把代理费用算进预算；该线还支持按需加配，$5/月加 1GB 内存或 1 个 CPU 核心，加购上限是原配置（4GB 内存的机器最多再加 4GB）。
